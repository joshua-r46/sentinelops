# Dashboard adapterThe static dashboard reads `GET /dashboard/overview` from the ShopStack API.The endpoint aggregates only existing read routes: ShopStack `/health`,AgentShield `/health` and `/incidents`, Deployer `/health` and `/deployments`,Worker `/metrics`, Safety Gate `/health`, and the optional Executor, Verifier,Snapshot Manager, and Recovery Policy `/health` routes. Unconfigured profileservices return as unavailable.The adapter does not proxy arbitrary paths, return credentials or Docker data,or expose control actions. There is no read-only list endpoint for approvalrequests, Executor history, or snapshots, so those dashboard sections stayunavailable.
